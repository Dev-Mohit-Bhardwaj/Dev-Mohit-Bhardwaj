## 🚀 Featured Projects

### 🤖 ContentForge AI Studio
**Multi-Agent Generative AI Content Creation Platform**

A multi-agent AI application where specialized agents collaborate to automate the content creation workflow:

**Planner → Researcher → Writer → Editor → Formatter**

- Generates structured and refined content from user requirements
- Configurable topic, content type, audience, tone, length and creativity
- Built with **Python, CrewAI, Gemini, Streamlit, FastAPI & Pydantic**

### 🛰️ Space Debris Risk Detection & Cleanup Optimization

An AI-powered system for assessing orbital debris risk and optimizing debris-removal strategies.

- Uses **TLE orbital data** and orbital parameters for risk analysis
- **Random Forest & XGBoost** for debris risk detection
- **Genetic Algorithm (DEAP)** for cleanup optimization
- Focuses on prioritizing high-risk debris while reducing spacecraft fuel requirements
